# IPs para liberação de Webhook

As notificações de **Webhook** da Positus são enviadas a partir de um conjunto fixo de servidores. Se a URL do seu Webhook está atrás de um **firewall**, **WAF** ou lista de permissões (*allowlist*), você precisa liberar os IPs de origem listados abaixo. Caso contrário, as requisições `HTTP POST` da Positus serão bloqueadas e você **não receberá** as notificações de mensagens e de status.

<Info>
Libere estes IPs apenas para **tráfego de entrada** (*inbound*) na URL onde seu Webhook está publicado. A Positus entrega as notificações via **HTTPS** (porta `443`).
</Info>
