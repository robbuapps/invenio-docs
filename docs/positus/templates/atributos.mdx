# Atributos dos Templates

Esta página descreve os valores que aparecem nos campos `status`, `quality_score`, `category`, `language`, `display_format` e `sub_category` do objeto de template, além dos demais campos retornados pela API.

## Objeto de template

As rotas de listagem, exibição e criação retornam o template neste formato:

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `id` | string (UUID) | Identificador do template na Positus. É o valor usado como `{template}` nas rotas |
| `wa_id` | string | Identificador do template na Meta |
| `meta_template_id` | string | Mesmo valor de `wa_id` |
| `type_model` | string ou `null` | Texto livre, informado na criação |
| `status` | objeto | `{ id, code, description }`. Veja [status](#status) |
| `quality_score` | objeto | `{ id, code }`. Veja [quality score](#quality-score) |
| `category` | objeto | `{ id, code, description }`. Veja [categorias](#categorias) |
| `language` | objeto | `{ id, code, name }`. Veja [idiomas](#idiomas) |
| `name` | string | Nome do template, já normalizado (ver [API de Templates](/docs/positus/templates/api#criar-template)) |
| `message_send_ttl_seconds` | integer ou `null` | Tempo de vida (TTL) da mensagem, em segundos |
| `components` | array | Componentes do template, no formato da Meta |
| `display_format` | objeto | `{ id, code, description }`. Só aparece quando definido |
| `sub_category` | objeto | `{ id, code, description }`. Só aparece quando definido |
| `header_file` | objeto ou `null` | Arquivo do header (`mime_type`, `original_name`, `name`, `url`, `size`) |
| `carousel_files` | array | Arquivos dos cards de um template de carrossel (mesmo formato de `header_file`) |
| `created_at`, `updated_at` | string (ISO 8601) | Datas de criação e atualização |

## Status

Define o status do template. O campo `status` retorna `id`, `code` e `description`.

| Id | Descrição | Code |
| --- | --- | --- |
| 0 | Indefinido | `UNDEFINED` |
| 1 | Pendente | `PENDING` |
| 2 | Aprovado | `APPROVED` |
| 3 | Rejeitado | `REJECTED` |
| 4 | Em recurso | `IN_APPEAL` |
| 5 | Exclusão pendente | `PENDING_DELETION` |
| 6 | Excluído | `DELETED` |
| 7 | Desabilitado | `DISABLED` |
| 8 | Sinalizado | `FLAGGED` |
| 9 | Reinstalado | `REINSTATED` |
| 10 | Pausado | `PAUSED` |
| 11 | Pausado | `PAUSED` |
| 12 | Arquivado | `ARCHIVED` |
| 13 | Desarquivado | `UNARCHIVED` |
| 14 | Bloqueado | `LOCKED` |
| 15 | Limite excedido | `LIMIT_EXCEEDED` |

<Info>
Os ids `10` e `11` têm o mesmo `code` (`PAUSED`) e a mesma descrição. Eles representam a primeira e a segunda pausa do template, e a única forma de distingui-los na API e nos webhooks é pelo `status.id`.
</Info>

Para filtrar a listagem por status, use o **id numérico** (por exemplo, `status=2`). Veja [Listar templates](/docs/positus/templates/api#listar-templates).

## Quality score

Define a qualidade do template. O campo `quality_score` retorna `id` e `code`.

| Id | Code |
| --- | --- |
| 0 | `UNKNOWN` |
| 1 | `GREEN` |
| 2 | `YELLOW` |
| 3 | `RED` |

## Categorias

Define a categoria do template. O campo `category` retorna `id`, `code` e `description`.

A coluna **Criação pela API** indica se a categoria é aceita no endpoint de criação. As categorias marcadas como descontinuadas continuam existindo na tabela, mas a criação com elas é rejeitada com `422`.

| Id | Descrição | Code | Criação pela API |
| --- | --- | --- | --- |
| 0 | Indefinido | `UNDEFINED` | Não aceita |
| 1 | Atualização da conta | `ACCOUNT_UPDATE` | Descontinuada |
| 2 | Atualização de pagamento | `PAYMENT_UPDATE` | Descontinuada |
| 3 | Atualização de finanças pessoais | `PERSONAL_FINANCE_UPDATE` | Descontinuada |
| 4 | Atualização de envio | `SHIPPING_UPDATE` | Descontinuada |
| 5 | Atualização de reserva | `RESERVATION_UPDATE` | Descontinuada |
| 6 | Resolução de problemas | `ISSUE_RESOLUTION` | Descontinuada |
| 7 | Atualização de compromisso | `APPOINTMENT_UPDATE` | Descontinuada |
| 8 | Atualização de transporte | `TRANSPORTATION_UPDATE` | Descontinuada |
| 9 | Atualização de suporte | `TICKET_UPDATE` | Descontinuada |
| 10 | Atualização de alerta | `ALERT_UPDATE` | Descontinuada |
| 11 | Resposta automática | `AUTO_REPLY` | Descontinuada |
| 12 | Transacional | `TRANSACTIONAL` | Descontinuada |
| 13 | Marketing | `MARKETING` | Aceita |
| 14 | Senhas descartáveis | `OTP` | Descontinuada |
| 15 | Serviços | `UTILITY` | Aceita |
| 16 | Autenticação | `AUTHENTICATION` | Aceita |

<Info>
Na criação, envie o **code** da categoria (`MARKETING`, `UTILITY` ou `AUTHENTICATION`) no campo `category`.
</Info>

## Display format

Define se um template é do tipo "detalhes do pedido". Aparece no objeto somente quando definido.

| Id | Descrição | Code | Criação pela API |
| --- | --- | --- | --- |
| 0 | Desconhecido | `UNKNOWN` | Não aceita |
| 1 | Detalhes do pedido | `ORDER_DETAILS` | Aceita |

## Sub category

Define se um template é do tipo "status do pedido". Aparece no objeto somente quando definido.

| Id | Descrição | Code | Criação pela API |
| --- | --- | --- | --- |
| 0 | Desconhecido | `UNKNOWN` | Não aceita |
| 1 | Status do pedido | `ORDER_STATUS` | Aceita |

<Info>
A rota [`GET /restrictions`](/docs/positus/templates/api#restrições) informa se o workspace possui a permissão `order_details`, relacionada ao uso de `display_format` e `sub_category`.
</Info>
