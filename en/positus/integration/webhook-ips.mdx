# Webhook IP addresses

Positus **Webhook** notifications are sent from a fixed set of servers. If your Webhook URL sits behind a **firewall**, **WAF**, or allowlist, you must allow the source IPs listed below. Otherwise Positus `HTTP POST` requests will be blocked and you will **not receive** message and status notifications.

<Info>
Allow these IPs for **inbound** traffic only, on the URL where your Webhook is published. Positus delivers notifications over **HTTPS** (port `443`).
</Info>
