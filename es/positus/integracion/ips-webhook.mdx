# IPs para liberación de Webhook

Las notificaciones de **Webhook** de Positus se envían desde un conjunto fijo de servidores. Si la URL de tu Webhook está detrás de un **firewall**, **WAF** o lista de permitidos (*allowlist*), debes permitir las IPs de origen listadas abajo. De lo contrario, las solicitudes `HTTP POST` de Positus serán bloqueadas y **no recibirás** las notificaciones de mensajes y de estado.

<Info>
Permite estas IPs solo para **tráfico de entrada** (*inbound*) en la URL donde tu Webhook está publicado. Positus entrega las notificaciones vía **HTTPS** (puerto `443`).
</Info>
